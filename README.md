# Тоо Туры

Каталог поездок по Кыргызстану на Next.js. Посетитель может подобрать тур, сохранить его в избранное, рассчитать цену для группы и отправить заявку.

## Запуск

Требуется Node.js 24 или новее. Выполняйте команды из корня проекта.

```sh
npm ci
npm run dev
```

В облачной среде с ограничением записи в домашнюю папку используйте `npm ci --cache /tmp/too-tury-npm-cache`.

Чтобы проверить сборку и запустить её, выполните следующие команды.

```sh
npm run typecheck
npm run build
npm run start
```

## Администрирование

В терминале сервера задайте пароль и откройте `/admin/login`. Команда запрашивает пароль дважды без вывода на экран. Пароль требуется длиной от 12 до 160 символов. Смена пароля завершает все действующие сеансы администратора.

```sh
npm run admin -- password
```

Панель управляет одним аккаунтом администратора. Используйте HTTPS при удалённом доступе и настройте прокси так, чтобы приложение получало исходный хост и протокол. На этой же машине можно войти через `http://127.0.0.1:3000/admin/login`.

- В **Турах** можно добавить карточку, загрузить обложку и галерею, настроить программу, доступные дни, тарифы и доплату за гида. «Сохранить черновик» записывает изменения для администратора. «Опубликовать» заменяет публичную версию. Снятие с публикации сохраняет черновик и ранее полученные заявки.
- В **Заявках** организатор видит список и статусы. Контакт открывается внутри заявки. После проверки даты и мест организатор связывается с клиентом и меняет статус вручную.
- В **Настройках сайта** меняются название, тексты главной, страница «О нас», телефон, почта и демонстрационный режим.

## Карта маршрута

Откройте тур в админке и разверните раздел **«Карта маршрута»**. Добавьте остановки кликом по карте или введите широту и долготу вручную, если у вас уже есть координаты. Укажите названия и расположите остановки по порядку. Сохраните черновик, чтобы продолжить позже, или опубликуйте тур, чтобы карта появилась во вкладке «Маршрут».

Пунктир показывает порядок остановок, а ссылка «Открыть в навигаторе» передаёт координаты выбранной точки. Для Ала-Арчи в демонстрационном каталоге показан пример с тремя остановками. Для публичного тура используйте точки, проверенные организатором.

Подложка загружается в браузере с `tile.openstreetmap.org`. При недоступности подложки посетитель всё равно видит схему, список остановок и ссылки на навигатор.

## Уведомления в Telegram

1. В личном чате нажмите «Запустить» у бота. Для группы добавьте бота и разрешите ему отправлять сообщения.
2. В админке откройте **Настройки сайта → Уведомления Telegram**. Укажите числовой ID чата и токен бота, включите уведомления и сохраните настройки. Пустое поле токена при последующем редактировании сохраняет прежний токен.
3. Нажмите «Отправить тестовое сообщение», чтобы проверить доступ бота к чату. Тестовое сообщение содержит только текст проверки.

Бот получает номер новой заявки, имя и контакт клиента, название и категорию тура, дату выезда, длительность, число участников, вариант с гидом и стоимость. Выберите чат, к которому имеют доступ сотрудники, обрабатывающие заявки.

Сайт сохраняет заявку и запись в очереди до отправки. Временные ошибки доставки повторяются с паузой, в том числе после перезапуска сервера. Смена чата или токена, удаление токена и выключение уведомлений отменяют ожидающие сообщения прежней настройки. В карточке заявки виден статус доставки. После исправления ошибки нажмите «Повторить отправку», чтобы поставить уведомление в очередь для текущего чата.

Серверу нужен исходящий HTTPS-доступ к `api.telegram.org`. Если среда маршрутизирует HTTPS через системный прокси, запускайте сервер с `NODE_USE_ENV_PROXY=1`. Сохранённый токен зашифрован, ключ хранится в файле `telegram.key` внутри `TOO_TURY_DATA_DIR` или `.data`. Храните ключ в закрытом хранилище и восстановите его вместе с базой, чтобы сохранить настройки бота.

## Заявки

Приложение хранит каталог, настройки, аккаунт администратора и заявки в SQLite по пути `.data/bookings.sqlite`. Загруженные фотографии находятся в `.data/tour-media/`. Для постоянного хранения укажите закрытый доступный для записи каталог через `TOO_TURY_DATA_DIR`. Используйте тот же путь для команд управления.

```sh
npm run bookings -- list
npm run bookings -- show TT-XXXXXXXXXXXX
npm run bookings -- confirm TT-XXXXXXXXXXXX
npm run bookings -- decline TT-XXXXXXXXXXXX
npm run bookings -- backup /папка-для-копий/bookings-YYYY-MM-DD.sqlite
```

Для резервной копии используйте закрытую папку и свободное имя файла. Команда `backup` сохраняет согласованный снимок SQLite даже во время работы сайта. Вместе с базой сохраните папку `tour-media/` и файл `telegram.key`, если они есть. Для полной копии приостановите изменения каталога, загрузку фотографий и изменение настроек Telegram до завершения копирования.

Чтобы проверить восстановление, поместите снимок под именем `bookings.sqlite` в отдельный закрытый каталог вместе с сохранёнными фотографиями и ключом. Запустите отдельный экземпляр с `TOO_TURY_DATA_DIR`, указывающим на этот каталог, и `TOO_TURY_TELEGRAM_PAUSED=1`. Такой экземпляр сохраняет очередь и приостанавливает отправку в Telegram. Проверьте каталог, фотографии и заявки.

Для восстановления рабочего сайта остановите сервер, восстановите исходную копию в новый закрытый каталог и направьте на него `TOO_TURY_DATA_DIR`. Задайте пароль заново, чтобы завершить сеансы из копии, и запустите сервер с рабочими настройками Telegram. Команды выполняйте от пользователя, который запускает приложение.

## Подготовка к публикации

1. Согласуйте с организатором программы, тарифы, график выездов и вместимость групп. Через админку замените или снимите с публикации демонстрационные туры и добавьте подтверждённые данные и фотографии. Исходный каталог импортируется один раз при создании базы. Оценки исходных туров отображаются только в деморежиме.
2. Укажите контакты и сведения об организаторе в настройках сайта. Определите, кто будет проверять заявки.
3. Разместите сайт как один Node.js-процесс за HTTPS. Укажите постоянный закрытый каталог в `TOO_TURY_DATA_DIR`, используйте его и для команд организатора. Регулярно сохраняйте резервные копии отдельно от рабочего каталога.
4. Когда каталог заполнен, выключите демонстрационный режим в админке и задайте адрес сайта в `TOO_TURY_SITE_URL`, например `https://tours.example.com`. Сайт разрешает индексацию публичных страниц и отдаёт карту опубликованных туров, когда готовы каталог и адрес.
5. Выполните `npm ci`, `npm run typecheck` и `npm run build`. После запуска проверьте поиск, открытие тура, расчёт и оформление. Для проверочных заявок укажите временный каталог в `TOO_TURY_DATA_DIR`, затем запустите сайт с основной базой.
